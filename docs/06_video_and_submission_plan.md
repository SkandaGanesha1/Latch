## Why this file still exists

There were **three** video/submission plans in the tree: this one, `docs/VIDEO_SCRIPT_AND_SUBMISSION.md`, and `docs/DEMO_VIDEO_SCRIPT.md`. Two of them were older copies of a storyboard that had since been corrected — most importantly the dead-man segment, whose lease figure and heartbeat count had been reconciled against the attack rig. A stale copy of a storyboard reads exactly like the live one, and an operator filming from the wrong file films a storyboard the code contradicts.

So the family now has exactly **one** canonical plan, and this file is the banner that says so. The consistency checker derives the canonical storyboard from the documents themselves and fails the build if a second one appears or if this banner is removed.
