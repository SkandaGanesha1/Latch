TECHNICAL ARCHITECTURE ANALYSIS:
1. QNX Microkernel Isolation:
   - ThreadCtl(_NTO_TCTL_RUNMASK, 0x1) pins latchd strictly to Core 0.
   - SCHED_FIFO priority 63 preempts all user processes (ksh, slogger2, ingest).
   - QNX Hypervisor 8.0 confines untrusted Linux guest vCPUs to Core 2 and Core 3
     at priority 8, eliminating cache pollution and context-switch interference.

2. Linux GPOS Limitations:
   - CFS completely fair scheduler lacks hard real-time admission guarantees.
   - Interrupt handling and background worker threads introduce tail latency spikes.
   - Running deep learning / agent loops on the same OS without hypervisor boundaries
     inevitably leads to multi-millisecond deadline misses.
